<h1 align="center">Folio</h1>

<p align="center">
  An independent, free native iPad app for Figma's web editor.
  <br>
  <a href="https://foliodesign.app"><strong>foliodesign.app</strong></a>
</p>

Folio opens figma.com in a native iPad shell and adds what a browser tab can't:

- **Tabs and windows**: several files at once, pinned tabs and multiple windows.
- **Apple Pencil, touch and trackpad**: input adapted to the standard browser events Figma already understands.
- **Bottom toolbar**: Shift, Control, Option and Command keys, arrows and edit commands without a keyboard.
- **Native downloads**: a download center, plus saving exports to Photos.
- **Crash recovery**: tabs reload safely after WebKit runs out of memory.

Folio doesn't change or reimplement Figma. It loads the real editor, so Figma's own features and updates work as they do in a browser.
